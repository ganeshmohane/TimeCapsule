<h1 align="center">⏳ TimeCapsule</h1>

<h3 align="center">A blockchain-based platform to send messages into the future 📬</h3>

---

TimeCapsule is a decentralized app built using **Solidity**, **Ganache**, and **Python** that lets users create digital "time capsules"—messages locked until a future date. Once that date is reached, the message is revealed automatically. A fun and secure way to preserve thoughts, reminders, or surprises for the future!
